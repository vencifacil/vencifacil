📋 1. Termos de Uso

1.1 Aceitação

Ao criar uma conta ou utilizar o VenciFácil, você declara que leu, entendeu e concorda com estes Termos de Uso. Se não concordar, não utilize o serviço.

1.2 O que é o VenciFácil

O VenciFácil é uma plataforma SaaS (Software como Serviço) para controle de validade de produtos em estabelecimentos comerciais como mercados, padarias, farmácias e afins. O sistema permite cadastro de produtos, alertas de vencimento, gestão de trocas e rebaixas, relatórios e importação de notas fiscais.

1.3 Uso permitido

  • O sistema é de uso exclusivo do estabelecimento contratante
  • Cada conta corresponde a um único estabelecimento
  • Não é permitido revender, copiar ou redistribuir o sistema
  • Não é permitido usar o sistema para fins ilegais

1.4 Responsabilidades do usuário

  • Manter suas credenciais de acesso em sigilo
  • Garantir a veracidade dos dados cadastrados
  • Realizar backups adicionais de dados críticos se necessário
  • Notificar imediatamente em caso de acesso não autorizado

1.5 Limitação de responsabilidade

O VenciFácil é uma ferramenta de auxílio ao controle de validades. O responsável pelo estabelecimento permanece integralmente responsável pelo controle físico dos produtos, vigilância sanitária e demais obrigações legais. O VenciFácil não se responsabiliza por perdas decorrentes de falhas no uso do sistema, falhas de conexão ou dados incorretamente cadastrados pelo usuário.

1.6 Disponibilidade

O sistema é fornecido "como está". Nos empenhamos para manter disponibilidade máxima, mas não garantimos 100% de uptime. Manutenções programadas serão comunicadas com antecedência via WhatsApp.

1.7 Alterações nos termos

Podemos atualizar estes termos a qualquer momento. Alterações significativas serão comunicadas com pelo menos 15 dias de antecedência. O uso continuado do serviço após notificação implica aceitação dos novos termos.

🔒 2. Política de Privacidade

Esta Política descreve como o VenciFácil coleta, usa, armazena e protege suas informações, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

2.1 Controlador dos dados

O responsável pelo tratamento dos seus dados pessoais é o operador do VenciFácil. Para contato, utilize os canais indicados na seção 7 deste documento.

2.2 Base legal

O tratamento de dados é realizado com base nos seguintes fundamentos legais previstos na LGPD:

  • Execução de contrato — para prestação do serviço contratado
  • Consentimento — para envio de comunicações e suporte
  • Legítimo interesse — para melhoria do serviço e segurança

📊 3. Dados Coletados

3.1 Dados do estabelecimento

  • Razão social e nome fantasia
  • CNPJ ou CPF do responsável
  • Endereço completo
  • Número de telefone/WhatsApp
  • Endereço de e-mail (usado como login)

3.2 Dados operacionais

  • Produtos cadastrados (nome, código de barras, validade, quantidade)
  • Histórico de trocas e rebaixas
  • Categorias e locais de armazenamento
  • Dados importados de notas fiscais (XML)

3.3 Dados de acesso

  • Credenciais de login (senha armazenada de forma segura)
  • Registros de acesso ao sistema

3.4 Dados que NÃO coletamos

  • Dados de pagamento (processados pelo Kiwify/Hotmart)
  • Dados de clientes finais do estabelecimento
  • Localização geográfica em tempo real

☁️ 4. Armazenamento e Segurança

4.1 Onde os dados são armazenados

Os dados são armazenados no Google Firebase Firestore, plataforma de banco de dados em nuvem do Google, com servidores localizados no Brasil (região southamerica-east1 — São Paulo).

4.2 Isolamento de dados

Cada estabelecimento tem seus dados armazenados em um namespace exclusivo e isolado. Um cliente nunca tem acesso aos dados de outro cliente.

4.3 Retenção de dados

  • Dados ativos: mantidos durante toda a vigência do contrato
  • Após cancelamento: dados mantidos por 30 dias para possível reativação
  • Após 30 dias do cancelamento: dados excluídos permanentemente

4.4 Medidas de segurança

  • Comunicação criptografada via HTTPS/TLS
  • Senhas nunca armazenadas em texto puro
  • Acesso ao banco de dados restrito por regras de segurança
  • Backups automáticos pelo Google Firebase
⚠️ Nenhum sistema é 100% seguro. Em caso de incidente de segurança que afete seus dados, você será notificado dentro de 72 horas conforme exigido pela LGPD.

⚖️ 5. Seus Direitos (LGPD)

Conforme a Lei Geral de Proteção de Dados, você tem os seguintes direitos:

  • Acesso — solicitar quais dados temos sobre você
  • Correção — corrigir dados incompletos ou desatualizados
  • Exclusão — solicitar a exclusão dos seus dados
  • Portabilidade — receber seus dados em formato exportável
  • Revogação — revogar o consentimento a qualquer momento
  • Informação — ser informado sobre o uso dos seus dados

Para exercer qualquer um desses direitos, entre em contato pelo WhatsApp ou e-mail indicados na seção 7. Responderemos em até 15 dias úteis.

5.1 Compartilhamento de dados

Seus dados não são vendidos, alugados ou compartilhados com terceiros para fins comerciais. Os dados podem ser compartilhados apenas com:

  • Google Firebase (armazenamento em nuvem)
  • Autoridades competentes, quando exigido por lei

5.2 Cookies

O VenciFácil utiliza apenas armazenamento local (localStorage e sessionStorage) no seu dispositivo para manter a sessão ativa. Não utilizamos cookies de rastreamento ou publicidade.

💳 6. Cancelamento e Reembolso

6.1 Trial gratuito

Novos clientes têm 30 dias gratuitos para testar o sistema sem necessidade de cartão de crédito. Ao final do trial, o acesso é suspenso até a contratação de um plano.

6.2 Cancelamento

  • O cancelamento pode ser solicitado a qualquer momento via WhatsApp
  • O acesso continua até o fim do período pago
  • Após o cancelamento, os dados ficam disponíveis por 30 dias para exportação

6.3 Reembolso

  • Direito de arrependimento: reembolso integral em até 7 dias após a primeira contratação (Código de Defesa do Consumidor, art. 49)
  • Após 7 dias: não há reembolso proporcional para o período em curso

6.4 Inadimplência

Em caso de não pagamento, o acesso será suspenso após 5 dias de atraso. Os dados são mantidos por 30 dias adicionais para regularização.
